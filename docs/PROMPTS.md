# Prompts

## Burst Circle Prompt

Create a page where clicking anywhere on the screen creates a burst of expanding colorful circles from the pointer position. Each click should spawn a cluster of rings that grow outward, fade as they expand, and cycle through changing colors with each burst. Keep the canvas full-screen, hide UI chrome, and make the animation smooth and responsive.

## Notes

- Use a full-screen canvas.
- Bind click/tap input to the canvas.
- Spawn multiple concentric rings per click.
- Cycle hues so every burst feels fresh.
- Fade each ring out as it expands.
